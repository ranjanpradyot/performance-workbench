## What this run does not prove

- Conditional formatting, every original column width, and every merged title range are not copied from the source file.
- ExcelJS does not calculate formulas. KPI weight formulas are written with a cached result computed in TypeScript.
- OKR summary and checklist summary sheets are rebuilt from checklist line weights. They are not a cell-for-cell copy of the source pivot.
- Helpdesk export writes the process checklist. The quarterly matrix and hygiene rows from the source sheet are kept in the application record and are not fully laid out again.
- A blank numeric cell stays blank. An explicit 0 is written as 0.
